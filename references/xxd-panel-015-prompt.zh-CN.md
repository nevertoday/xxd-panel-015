# XXD Panel 015｜极简抽象记忆编辑生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前任务明确提供的这一张源照片。先锁定主体或不可拆分关系、轮廓、姿态、动作、空间与叙事关系，至少保留三个源图专属结构线索。不要借用旧成品、样张或其他输入的形体、配色、文案和构图。

## 解构—筛选—提炼—重构

把源图解构为体量比例、主轴与次轴、关键曲线、开口、穿插、层叠、遮挡、负空间、尺度差、距离和非对称平衡。筛选出识别与记忆不可缺少的少数事实，再把每个事实提炼成一个明确几何角色，最后重构为一个连贯的抽象记忆，而不是把所有部件画成图解。

人物保留姿态、朝向、身体或衣着体量与关系距离；动物保留身体节奏和头部方向；植物保留生长曲线；建筑保留天际线、轴线和关键开口；物件与交通工具保留功能体量和负形；景观保留源图专属的地平线、地形曲线或空间关系。

必须一眼感受到与源图的对应，但不完整复刻轮廓。每一个形体都要承担身份、重量、动作、空间关系或记忆，禁止只是“看起来现代”的装饰几何。

## 少量形体与一个视觉记忆

使用少量且受控的圆、椭圆、矩形、长条、圆弧、楔形、不规则平面或定制简轮廓；只有在形体直接对应已锁定结构事实时才使用。

保留源图最独特的比例与关系：长轴对紧凑体量、曲线对长条、开口嵌入主体、一个形体从另一个背后穿过、被遮挡的边缘、狭窄间隙或刻意失衡。可使用平面叠压和极克制的空间提示，但不做渐变、照片级体积和 3D 对象。

构图围绕一个视觉重心，用尺度差、主次层级、正负形、遮挡、对齐和留白节奏组织。大面积干净象牙色背景必须保留；禁止平均排列、填满空白、零碎堆积、模块等大、图标化、徽标化和通用包豪斯组合。

## 严格的源图色彩角色

全部色彩来自源图，并收敛为一个主色、一个深色结构色、一个浅色或中性色；仅在源图明确支持时增加极少量关键强调色。

优先保留最有辨识度、最有精气神的颜色，不按像素平均取色，也不把整体降灰。通过面积比例、深浅关系和局部对比建立层次：主色承载记忆，深色固定轴线、遮挡或文字，浅／中性色打开空间。

象牙色背景必须与浅色形体保持可辨边界。禁止颜色平均分配、多色混杂、固定色卡、数字渐变、氛围阴影、脏旧滤镜和源图无依据的装饰色。

## 编辑式微排版

服从已锁定的自动文案、用户准确文案或无文字模式，以及目标语言／地区。用户准确文案逐字保留；无文字时不生成任何字母、字符、数字或伪文字。

自动文案从源图的光影、空间、动作、材质、关系或情绪中提炼一个 2–5 词的诗意主标题，并搭配 2–4 组微型辅助文字。小字可从短句、状态词、用户提供或可确认的地点／对象信息、构图编号、章节标记、序列号、尺度式数字、方向词、材质词、档案标签或微型说明中选择。

自动文案不得发明或使用年份。地点、日期、出处和事实数字必须由用户提供或可靠确认。用户准确文案即使包含年份也逐字保留；“不用年份”只约束自动创作，不覆盖用户原文。

主标题负责情绪，小字负责秩序、证据、材质、序列和阅读节奏。沿几何轴线、边缘、轮廓、色块或负空间排列，可按文字系统自然能力使用纵排、旋转、分栏、字距、贴边、压角、跨色块、嵌入形体或穿插对齐。至少一组极小、一组稍大，形成明确阅读路径。

使用目标文字系统自然的克制衬线与细瘦编辑字体等价物。不得把拉丁字距、旋转或小型大写强套给中文、日文、韩文或阿拉伯文，也不得使用粗大通用标题、界面字、霓虹、立体字和后贴标签。

## 模式与验收


硬性验收：至少三个源图结构线索；明确的解构—筛选—提炼—重构逻辑；少量形体、一个视觉记忆、强尺度层级、清楚正负形和大面积象牙色留白；体量比例、轴线、曲线、穿插、层叠、遮挡、负空间与非对称来自源图；色彩严格为主色＋深结构色＋浅／中性色＋至多少量强调色；2–5 词主标题与 2–4 组准确微文字形成阅读路径；自动文案无年份，用户准确文案逐字保留；无通用图标、徽标、平均排列、碎片堆积、无意义圆条组合、整体灰化、渐变、复杂拼贴、商业模板、照片残片或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
